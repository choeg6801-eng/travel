# Momentrip

시기·기간·비용·취향·여행 스타일로 **나라 3곳 → 도시 3곳 → 코스 3안 → 일자별 일정**을 추천해 주는 나만의 AI 여행 큐레이터.

- 화면: `index.html` + `img/` + `icons/`, `manifest.webmanifest`, `sw.js`(앱 설치·오프라인)
- AI: `api/ai.js` (Vercel 서버 함수 · Google Gemini 무료 또는 Claude · 키는 서버에만)
- 로그인·저장·사진: Supabase (프로젝트 `soundtrack-credit`에 `momentrip_` 테이블과 `momentrip-photos` 저장소로 이미 만들어 둠)

휴대폰과 컴퓨터에서 **같은 이메일로 로그인하면 같은 여행·기록·사진**이 보여요.

---

## 배포하기 (한 번만)

### 1. GitHub에 올리기
1. github.com → **New repository** → 이름 `momentrip`, **Private** 추천 → Create.
2. 새 저장소 화면의 **uploading an existing file** → 이 폴더 안의 파일과 폴더를 전부 끌어다 놓기 → **Commit changes**.
   (`index.html`, `api/`, `img/`, `icons/`, `manifest.webmanifest`, `sw.js`, `supabase/`, `vercel.json`, `package.json`, `README.md`, `.gitignore`)

### 2. Vercel에 배포
1. vercel.com → **Add New… → Project** → 방금 만든 GitHub 저장소 **Import**.
2. Framework Preset은 **Other** 그대로, Build 설정은 건드리지 않아요.
3. **Environment Variables**에 두 개 추가:

   | 이름 | 값 |
   |---|---|
   | `GEMINI_API_KEY` | **무료** — aistudio.google.com → Get API key → Create API key 로 만든 키 (카드 필요 없음) |
   | `ALLOWED_EMAILS` | 서비스(AI 추천)를 쓸 수 있는 이메일. 여러 개면 쉼표로 `a@x.com,b@y.com` · 도메인 전체는 `@naver.com` · 로그인한 누구나는 `*` |

   **(선택) 장소 정확도를 더 높이는 키 두 개** — 없어도 동작해요(그땐 OpenStreetMap만 써요).

   | 이름 | 하는 일 | 받는 곳 |
   |---|---|---|
   | `KAKAO_REST_API_KEY` | **국내 여행**: 카카오맵에서 지금 영업 중인 실제 장소를 조건에 맞게 모아 AI가 그 안에서만 고르게 하고, 장소 확인도 카카오맵으로 해요. **무료.** | developers.kakao.com → 내 애플리케이션 → 앱 추가 → 앱 키의 **REST API 키**, **제품 설정 → 카카오맵** 사용 설정 |
   | `TOURAPI_KEY` | **국내 여행**: 한국관광공사 공식 데이터로 **여행 시기에 열리는 지역 축제·행사**(날짜·장소)와 **관광공사에 등록된 숙소**를 가져와요. **무료.** | data.go.kr 회원가입 → "한국관광공사_국문 관광정보 서비스_GW" 검색 → **활용신청**(개발계정은 바로 승인) → 마이페이지의 **일반 인증키**(Encoding/Decoding 아무거나) |
| `TICKETMASTER_API_KEY` | **해외 여행**: 여행 날짜에 여행지 40km 안에서 열리는 **콘서트·스포츠·공연**을 가져와요(미주·유럽·호주에 강하고 아시아는 적어요). 무료(하루 5,000건). | developer.ticketmaster.com → 가입 → My Apps의 **Consumer Key** |
| `GOOGLE_PLACES_API_KEY` | **해외 여행**: ① 그 도시의 맛집·카페를 **Google 평점·리뷰 수·가격대**와 함께 모아 후보에 넣고(영업 중이고 평점 4.0 이상만, 도시 하나에 약 4~5건 · 월 1,000건 무료, 같은 도시는 7일간 다시 안 불러요) ② 장소마다 **폐업·임시 휴업**을 잡아내고 공식 이름으로 고쳐요(월 5,000건 무료, 코스 1개에 약 20건). | console.cloud.google.com → 결제 계정 연결(카드 등록, 무료 한도 안에선 청구 없음) → **Places API (New)** 사용 설정 → 사용자 인증 정보 → API 키. 키 제한에서 Places API (New)만 허용해 두세요. |

   Claude를 쓰고 싶으면 `GEMINI_API_KEY` 대신 `ANTHROPIC_API_KEY`(platform.claude.com, 유료 충전)를 넣으면 돼요. 둘 다 있으면 Gemini가 먼저 쓰이고, `AI_PROVIDER=claude`를 넣으면 Claude를 써요. Gemini 모델을 직접 고르려면 `GEMINI_MODEL`(예: `gemini-3.8-flash`)을 넣어요.

4. **Deploy** → 끝나면 `https://momentrip-xxxx.vercel.app` 같은 주소가 나와요.

### 3. Supabase에 내 사이트 주소 알려 주기 (로그인 링크용)
supabase.com → 프로젝트 **soundtrack-credit** → **Authentication → URL Configuration**
- **Redirect URLs**에 `https://내-vercel-주소/**` 추가 → Save.
- ⚠️ **Site URL은 바꾸지 마세요.** 같은 프로젝트를 쓰는 다른 앱이 쓰고 있어요.

**로그인 메일 관련 (중요)**
- Supabase 기본 메일 발송은 **이 Supabase 조직(팀) 멤버의 이메일로만** 보내고, **시간당 몇 통**으로 제한돼요. 혼자 쓴다면 **Supabase에 가입한 이메일로 로그인**하면 돼요. 다른 이메일도 쓰려면 Authentication → Emails → SMTP Settings에서 Resend 같은 메일 서비스를 연결하세요.
- (추천) **Authentication → Emails**의 **Magic Link**와 **Confirm signup** 템플릿 본문에 `{{ .Token }}` 한 줄을 넣어 두세요. 메일에 6자리 코드가 같이 와서, 메일 앱 안에서 링크가 열려 로그인이 엉뚱한 브라우저에 될 때 코드를 앱에 직접 넣을 수 있어요.

### 4. 사용
- 컴퓨터와 휴대폰에서 사이트를 열고 **같은 이메일**로 로그인 → 메일의 링크를 누르면 끝.
- 한 번 로그인하면 그 기기에서는 계속 로그인돼 있어요. 한 기기에서 로그아웃해도 다른 기기는 로그인 상태가 유지돼요.
- 휴대폰은 브라우저 공유 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 열려요.

## 주요 기능
- **꼭 원하는 곳**: "오션뷰 LP바", "루프탑 수영장 있는 호텔"처럼 구체적으로 말한 건 요약하지 않고 그대로 조건 패널의 **꼭 원하는 곳**에 담아요. 요청마다 지도에서 따로 검색하고(카카오/구글/OpenStreetMap/위키보이지), **종류는 카테고리·이름으로, 오션뷰는 실제 해안선까지 거리로** 확인해 근거를 붙여요(예: "LP바 ✓, 오션뷰 ✓(해안 49m)"). 완전히 맞는 곳이 있으면 AI가 다른 곳을 골라도 그곳으로 바꿔 넣고, 없으면 비슷한 곳으로 몰래 채우지 않고 **✓ 반영됨 / △ 일부만 / ✗ 못 찾음**으로 솔직하게 보여 줘요. "코스 고치기"에 새로 적은 요청도 같은 방식으로 찾아요. 숙소 요청(오션뷰·수영장 등)은 숙소 추천에 반영돼요.
- **평점·리뷰 우선**: `GOOGLE_PLACES_API_KEY`가 있으면 국내·해외 모두 맛집·카페·명소의 Google 평점과 리뷰 수를 가져와, 리뷰 수까지 고려한 점수(리뷰가 적으면 평균 쪽으로 끌어당김)로 후보 순서를 정해요. 리뷰 30개 이상인데 ★3.9 미만이거나 폐업한 곳은 다른 출처에 있어도 빼요. 일정에는 ★4.6 (3.2천)처럼 평점이 붙어요.
- **최적 동선**: 후보마다 좌표를 AI에게 주고 가까운 곳끼리 묶게 한 뒤, 하루마다 실제 거리를 계산해 지그재그가 없는 순서로 다시 정리해요(점심·저녁 맛집은 식사 시간에, 바는 저녁에 두고, 이동·숙소·행사는 고정). 다른 날 동네에 잘못 들어간 장소는 같은 종류끼리 맞바꿔요. 하루마다 이동 거리와 **이 순서로 경로 보기**(Google 지도), **동선 다시 정리** 버튼이 있어요. 숙소를 정하면 숙소에서 출발·도착하는 기준으로 정리해요.
- **여행지 검증**: 추천 카드마다 도시 3곳이 실제 지도에 있는지(Open-Meteo 지오코딩), 출발지에서 거리로 계산한 직항 비행시간(AI 추정과 2시간 넘게 다르면 표시), 그 달의 실제 날씨(지난 3년), 외교부 여행경보(TOURAPI_KEY와 같은 data.go.kr 키로 "외교부_국가·지역별 여행경보" 활용신청)를 확인해요. 범위를 벗어나거나 경보 3~4단계, 야외 여행인데 비 오는 날이 많은 곳은 점수를 낮추고 순위를 다시 매겨요.
- **영업시간 확인**: 출발일을 넣으면 일정의 각 장소가 그 요일·그 시간에 실제로 여는지 Google 지도 영업시간으로 확인해요(휴무일·영업 전/후 표시, `영업시간에 맞게 고치기`). Google Place Details는 월 1,000건 무료라 장소당 7일 동안 저장해 다시 쓰지 않아요.
- **지도**: 장소의 지도 버튼을 누르면 네이버 지도·카카오맵·Google 지도 중 골라 열 수 있어요(API 키 필요 없음). 코스 화면에는 그날 장소를 번호와 동선으로 그린 지도가 나와요(Leaflet + OpenStreetMap/CARTO, 무료).
- **실제 장소로만 코스 짜기**: 일정을 만들기 전에 지도 데이터에서 그 도시의 실제 장소를 내 취향·스타일·동행에 맞춰 모아요(국내는 카카오맵, 해외는 OpenStreetMap + **위키보이지**의 여행자 추천 맛집·카페(가격대·소개 포함, 키 필요 없음) + Google 평점(키가 있을 때)). 프랜차이즈·먼 곳·폐업 표시된 곳은 빼고, 여러 출처에 함께 나온 곳, 평점·리뷰가 많은 곳, 위키백과에 실린 곳, 한국어 이름이 등록된(한국 사람이 많이 찾는) 곳을 앞에 두고, 예산에 "가성비"가 있으면 저렴한 곳을, "고급"이면 고급 식당을 우선해요. 폐업했다고 적힌 곳, 6년 넘게 아무도 확인하지 않은 위키보이지 정보, 평점 4.0 미만은 빼요. AI는 이 후보 안에서만 고르고, 장소마다 **내 조건과 맞는 이유**를 함께 적어요.
- **장소 확인·교정**: 장소마다 **✓ 지도 확인 / ? 확인 필요 / 폐업**을 표시하고, 이름이 틀리면 공식 이름으로, 종류가 틀리면(맛집↔카페) 실제 종류로 고쳐요. **실제 장소로 바꾸기** 버튼은 확인 안 된 곳·폐업한 곳만 후보 안의 다른 곳으로 바꿔요. 직접 확인했으면 배지를 눌러 **내가 확인함**으로 표시하면 돼요.
- **숙소 추천**: 코스 화면의 **내 일정에 맞는 숙소 찾기**를 누르면, 일정 장소들의 한가운데(멀리 가는 하루 일정은 빼고)에서 8km 안의 실제 숙소를 모아요 — 국내는 카카오맵 숙박·한국관광공사 등록 숙소, 해외는 OpenStreetMap(성급)·위키보이지(가격대·요금)·Google 평점. 영업 안 하는 곳·평점 3.8 미만은 빼고, 여러 곳에 함께 나온 숙소를 앞에 두고, 내 예산(코스의 숙박비 추정)·동행(가족이면 리조트, 연인이면 부티크·한옥 등)에 맞춰 AI가 4곳(가장 잘 맞는 곳 + 가격대가 다른 대안)을 골라 이유와 팁을 적어요. **여기로 정하기**를 누르면 일정의 숙소 칸과 예약 링크가 그 숙소로 바뀌어요. 요금·빈 방은 날짜에 따라 달라서 예약 사이트에서 확인해요.
- **이 시기 행사·축제**: 여행 시기(출발일, 없으면 "12월" 같은 조건)에 열리는 행사를 모아요 — 국내는 한국관광공사 축제 일정(여행지 50km 안)·공휴일, 해외는 그 나라 공휴일(Nager.Date)·위키보이지의 축제 정보(그 달에 열리는 것만)·Ticketmaster 공연. 코스를 만들 때 AI가 취향에 맞는 행사를 날짜에 맞춰 일정에 넣고, 공휴일엔 붐비거나 문 닫는 곳을 팁으로 알려 줘요. 카드에서 **일정에 넣기**로 바로 추가할 수도 있어요. 출발일을 바꾸면 그 날짜로 다시 찾아요.
- **연차로 길게 쉬기**: 한국 공휴일·대체공휴일(2026~2027)로 가진 연차에 맞는 가장 긴 연휴를 찾아 시기·기간에 바로 넣어요. 공휴일이 바뀌면 `index.html`의 `KR_HOLI`를 고치면 돼요.
- **실제 데이터**: 추천마다 그 달의 평균 기온·비 온 날(Open-Meteo, 지난 3년 관측), 오늘 환율(open.er-api.com), 직선거리를 AI 추정값과 구분해 보여 줘요. 키 없이 쓰는 무료 서비스예요.
- **여행 취향 프로필**: 여행 기록으로 AI가 취향을 정리하고, 직접 고칠 수 있어요. 다음 추천에 반영돼요.
- **3곳 비교표**, **답이 나오는 대로 순서대로 표시**(스트리밍).
- **여행 중 모드**: 출발일을 넣으면 오늘 일정·다음 일정, 15일 이내 일기예보, 비 오는 날 대체 일정 버튼, 다녀온 곳 체크.
- **동행 투표**: 추천 3곳으로 투표 링크를 만들어 보내면, 로그인 없이 이름만 적고 투표해요.
- **지출 기록**: 현지 통화로 적으면 원화로 바꿔 예상 경비와 비교하고, 여행이 끝나면 기록에 자동으로 채워요.
- **앱처럼 설치·오프라인**: 휴대폰에서 "홈 화면에 추가"하면 앱처럼 열리고, 인터넷이 없을 때도 마지막으로 불러온 여행을 볼 수 있어요.

## 알아 두면 좋은 것
- **AI는 `ALLOWED_EMAILS`에 있는 계정만** 쓸 수 있어요. 다른 사람이 가입해도 AI 요금을 쓸 수 없고, 내 여행·기록·사진도 볼 수 없어요(행 단위 잠금).
- Supabase 기본 메일 발송은 **시간당 몇 통**으로 제한돼요. 로그인 메일이 안 오면 조금 뒤 다시 받아요. 한 번 로그인하면 거의 다시 받을 일이 없어요.
- Supabase 무료 프로젝트는 **일주일 넘게 아무도 안 쓰면 일시정지**돼요. 그땐 Supabase 대시보드에서 Restore를 누르면 돼요.
- Gemini 무료 요금제는 분당·하루 사용량 한도가 있고, 보낸 내용이 Google의 서비스 개선에 쓰일 수 있어요. Claude 키를 쓸 때는 앱의 **설정**에서 모델을 바꿀 수 있어요.
- **설정 → 전체 백업 받기**로 여행과 기록을 JSON 파일로 받아 둘 수 있어요.
- API 키를 바꾸려면 Vercel → Project → Settings → Environment Variables에서 수정하고 **Redeploy**.

## 문제가 생기면
| 증상 | 확인할 곳 |
|---|---|
| "AI 서버에 API 키가 없어요" | Vercel의 `GEMINI_API_KEY` 이름·값 확인 후 **Redeploy** |
| "무료 AI 사용량을 다 썼거나…" | Gemini 무료 한도. 잠시 뒤나 다음 날 다시 |
| "이 계정은 AI를 쓸 수 없어요" | Vercel의 `ALLOWED_EMAILS`에 로그인한 이메일이 있는지 |
| 로그인 링크를 누르면 다른 사이트로 감 | Supabase Redirect URLs에 Vercel 주소가 있는지 |
| "로그인 링크가 만료됐어요" | 링크는 한 번만, 1시간 안에 써야 해요. 새로 받기 |
